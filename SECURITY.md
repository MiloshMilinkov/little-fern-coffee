# Security Policy

## Reporting a vulnerability

Please **do not** open a public issue for security problems.

Report them privately through GitHub:
**[Report a vulnerability](https://github.com/MiloshMilinkov/little-fern-coffee/security/advisories/new)**

If that isn't possible, email milos300399@gmail.com with "SECURITY" in the subject.

Please include:

- what the problem is and where (URL or file);
- steps to reproduce it;
- the impact you think it has.

You'll get a reply as soon as possible. Please give a reasonable time to fix the issue before disclosing it anywhere.

## Please don't

- scan, brute-force or load-test the live site;
- access, change or delete data that isn't yours.

## Scope

Only the code in this repository and the site deployed from it (https://little-fern-coffee.milos300399.workers.dev) are in scope.
